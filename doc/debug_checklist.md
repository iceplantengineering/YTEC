# デバッグチェックリスト

## 事前確認
- [ ] PLCの電源が入っていること
- [ ] PCとPLCのLANケーブルが接続されていること
- [ ] PCのIPアドレス設定が正しいこと
- [ ] Redis Serverが起動していること (`redis-server.exe`)
- [ ] 必要なLuaライブラリ (`socket`, `redis` 等) がインストールされていること

## PLCロジック確認 (Simulator/実機)
- [ ] **STロジック動作**
    - [ ] 入庫条件 (`Src>0, Dest=0`) で `TaskType=100` になる
    - [ ] 出庫条件 (`Src=0, Dest>0`) で `TaskType=200` になる
    - [ ] 移動条件 (`Src>0, Dest>0`) で `TaskType=300` になる
- [ ] **IO信号**
    - [ ] 非常停止SW (X40, X41) が入力されていること (b接点注意)
    - [ ] リミットスイッチ等のセンサ入力が正常に読み取れていること

## 通信確認
- [ ] `TConEquipmentTest.lua` 起動時にエラーが出ないこと
- [ ] PLCとの接続 (`Connect`) が成功すること
- [ ] Redisへの接続が成功すること

## 運用テスト
- [ ] **ケース1: 入庫**
    - [ ] WMS(Redis)からタスク投入
    - [ ] PLCで受信確認 (`D3009`等)
    - [ ] `D330`が変化
    - [ ] 搬送開始 (シミュレーション上の完了まで)
    - [ ] Redisに完了報告が書き込まれる
- [ ] **ケース2: 出庫**
    - [ ] WMS(Redis)からタスク投入
    - [ ] PLCで受信確認
    - [ ] `D330`が変化
    - [ ] 搬送開始
    - [ ] 完了報告
- [ ] **異常系**
    - [ ] 非常停止ボタン押下でシステムが停止すること
    - [ ] 復帰操作で再開できること
