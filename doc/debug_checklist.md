# デバッグチェックリスト

## 1. 事前確認
### 1.1 ハードウェア・ネットワーク
- [ ] PLCの電源が入っていること
- [ ] PCとPLCのLANケーブルが接続されていること
- [ ] PCのIPアドレス設定が正しいこと（各PLCと同一セグメント）

### 1.2 ソフトウェア
- [ ] Redis Serverが起動していること (`redis-server.exe`)
- [ ] 必要なLuaライブラリ (`socket`, `redis`, `cjson8/9` 等) がインストールされていること
- [ ] Luaスクリプトが正常に実行できること

## 2. Modbus/TCP通信確認

### 2.1 接続確認
- [ ] `TConEquipmentTest.lua` 起動時にエラーが出ないこと
- [ ] PLCとの接続 (`Connect`) が成功すること
- [ ] `checkConnect()` メソッドが正常に動作すること

### 2.2 通信動作確認
- [ ] PLCレジスタ読み取り (`reader()`) が正常に動作すること
- [ ] PLCレジスタ書き込み (`writer()`) が正常に動作すること
- [ ] `TModbusHelper` 関連のエラーが発生しないこと

### 2.3 レジスタ値確認
| レジスタ | 期待値 | 確認事項 | 結果 |
|---------|--------|---------|------|
| D3000 | タイマー値 | ハートビート更新 | [ ] |
| D3002 | 設備状態 | 正常に読み取れる | [ ] |
| D3009 | 搬入台番号 | 正常に書き込める | [ ] |
| D3010 | 搬出台番号 | 正常に書き込める | [ ] |
| D339 | SrcStation | 正常に書き込める | [ ] |
| D340 | DestStation | 正常に書き込める | [ ] |

## 3. CC-Link通信確認

### 3.1 CC-Link接続状態
- [ ] CC-Linkマスターユニットが正常動作していること
- [ ] すべてのスレーブ局（スタッカー、コンベア）がオンラインであること
- [ ] SB49（ユニットステータス）に異常がないこと

### 3.3 CC-Link信号マッピング
- [ ] B00-BFF（コンベア→地上盤）の値が正常に読み取れること
- [ ] B1000-B1023（地上盤→コンベア）の値が正常に書き込めること
- [ ] RFIDデータ（W0-W13, W10-W23）が正しく転送されること

## 4. PLCロジック確認 (Simulator/実機)

### 4.1 STロジック動作
- [ ] 入庫条件 (`D339>0, D340=0`) で `D330=100` になる
- [ ] 出庫条件 (`D339=0, D340>0`) で `D330=200` になる
- [ ] 移動条件 (`D339>0, D340>0`) で `D330=300` になる

### 4.2 入力信号
- [ ] 非常停止SW (X40, X41) が入力されていること (b接点注意)
- [ ] リミットスイッチ等のセンサ入力が正常に読み取れていること
- [ ] CC-Link入力（M1000〜）が正常に更新されていること

### 4.3 タスク管理
- [ ] タスク待機状態（M3800）が正しく判定されること
- [ ] タスクタイプ判定（M3831-M3834, M3821-M3824）が正しく動作すること
- [ ] タスク完了処理が正常に実行されること

## 5. 運用テスト

### 5.1 ケース1: 入庫
- [ ] WMS(Redis)からタスク投入 (`LPUSH taskInfo`)
- [ ] Luaがタスクを検知 (`RPOP`)
- [ ] PLCで受信確認 (`D3009`, `D3010`)

- [ ] 搬送開始（シミュレーション上の完了まで）
- [ ] Redisに完了報告が書き込まれる

### 5.2 ケース2: 出庫
- [ ] WMS(Redis)からタスク投入
- [ ] PLCで受信確認
- [ ] `D330`が変化
- [ ] 搬送開始
- [ ] 完了報告

### 5.3 ケース3: 移動（入庫→出庫）
- [ ] WMS(Redis)からタスク投入
- [ ] PLCで受信確認
- [ ] `D330=300` になること
- [ ] 搬送開始
- [ ] 完了報告

### 5.4 異常系

## 6. トラブルシューティング

### 6.1 Modbus/TCP関連
| 症状 | 原因 | 対処 |
|------|------|------|
| 接続失敗 | IPアドレス間違い | 正しいIPを設定 |
| タイムアウト | PLC電源OFF | PLC電源投入 |
| 読取エラー | レジスタアドレス間違い | 正しいアドレスを指定 |

### 6.2 CC-Link関連
| 症状 | 原因 | 対処 |
|------|------|------|
| M370/M371/M372 OFF | スレーブ局通信異常 | ケーブル接続確認 |
| データ更新なし | マスターユニット異常 | ユニット交換 |
| RFIDデータ不正 | バッファサイズ間違い | Wレジスタ範囲確認 |

### 6.3 STロジック関連
| 症状 | 原因 | 対処 |
|------|------|------|
| D330が変化しない | D339/D340が0 | 入力値確認 |
| D330が異常値 | STロジック未実行 | スキャン順序確認 |
