## 6. Modbus/TCP通信マップ

### 6.1 接続設定

| 項目 | 設定値 |
|------|--------|
| プロトコル | Modbus/TCP |
| 実装Luaファイル | `TConEquipmentTest.lua`, `TClientHelper` |
| デフォルトポート | 502 |
| 機能コード（読取） | 0x03 (Read Holding Registers) |
| 機能コード（書込） | 0x06 (Write Single Register), 0x10 (Write Multiple Registers) |

### 6.2 主な通信レジスタ

| レジスタ | Modbusアドレス | 名称 | 方向 | 説明 |
|---------|---------------|------|------|------|
| D3000 | 3000 | システムハートビート | R/W | タイマー値 (T0) |
| D3002 | 3002 | 設備状態 | R | 各種フラグ |
| D3003 | 3003 | エラーコード | R | |
| D3009 | 3009 | 搬入台車番号/ST番号 | W | Lua→PLC |
| D3010 | 3010 | 搬出台車番号/ST番号 | W | Lua→PLC |
| D330 | 330 | タスク種別 | R/W | STロジックで判定 |
| D331 | 331 | 受信タスクID | R/W | |
| D339 | 339 | 搬入元ステーション | W | Lua→PLC (WriteSrcStation) |
| D340 | 340 | 搬出先ステーション | W | Lua→PLC (WriteDestStation) |
| D400 | 400 | WMS指示タスクタイプ | R | WMS→Lua→PLC |
| D401 | 401 | WMS指示タスクID | R | |

### 6.3 TConEquipmentTest.lua 通信処理

| メソッド | 機能 | Modbus機能コード |
|---------|------|-----------------|
| `reader()` | PLCレジスタ読み取り | 0x03 |
| `writer()` | PLCレジスタ書き込み | 0x06, 0x10 |
| `checkConnect()` | 接続状態確認 | - |
| `sendToServer22()` | データ送受信実行 | - |

*※ 備考欄の `(Seq. #)` は、システムアーキテクチャ記述の「詳細ワークフロー」図中の番号に対応します。*
