# GX Works ASCファイルインポート手順書

**作成日:** 2026-02-18
**対象:** Mitsubishi Q/iQシリーズ PLC
**対象ソフト:** GX Works2 / GX Works3

---

## 1. 概要

本ドキュメントは、REFACTフォルダ内のASCファイルをGX Worksにインポートし、パラメータ設定を行う手順を説明します。

### 対象ASCファイル

| ファイル名 | 用途 | プロジェクトタイプ |
|-----------|------|-------------------|
| `GroundPanel_Refactored_Q_GXW.asc` | 地上盤PLC | Qシリーズ（CC-Linkマスタ） |
| `Conveyor_Refactored_Q_GXW.asc` | コンベアPLC | Qシリーズ（CC-Linkスレーブ） |
| `StackerCrane_Refactored_Q_GXW.asc` | スタッカークレーンPLC | Qシリーズ（CC-Linkスレーブ） |

---

## 2. 事前準備

### 2.1 必要なソフトウェア

| ソフトウェア | バージョン | 用途 |
|-------------|-----------|------|
| GX Works2 | Ver1.5X以降 または | プロジェクト作成・ASCインポート |
| GX Works3 | Ver1.0XX以降 | プロジェクト作成・ASCインポート |

### 2.2 テンプレートプロジェクトの作成（推奨）

オフラインで事前にテンプレートを作成することで、現場作業時間を大幅に短縮できます。

```
テンプレートに含めるもの：
├─ プロジェクトファイル（.qgp / .qgw）
├─ IOアサイン設定（X/Yデバイス）
├─ CC-Linkパラメータ設定
├─ デバイスコメント（日本語）
└─ 空のラダープログラム（枠のみ）
```

## 3. プロジェクトの新規作成

### 3.1 GX Works2の場合

```
1. GX Works2を起動
2. [ファイル] → [新規プロジェクト作成]
3. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   PLCシリーズ              Qシリーズ（QCPU）
   PLCタイプ                Q03UDV または Q04UDH（実機に合わせる）
   プログラム言語           ラダー
   プロジェクト名           GroundPanel など
   保存先                   任意のフォルダ
```

### 3.2 GX Works3の場合

```
1. GX Works3を起動
2. [ファイル] → [新規プロジェクト]
3. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   PLCシリーズ              iQ-Rシリーズ または Qシリーズ
   PLCタイプ                実機に合わせる
   プログラム言語           ラダー
```

## 4. IOアサイン設定

### 4.1 入力デバイス（X）の設定

**GX Works2:**

```
1. [パラメータ] → [PLCタイプ] → [IO割付]
2. [X]タブを選択
3. 以下の範囲を設定：

   開始    終了     コメント
   ─────────────────────────────────────
   X000    X0FF    入力モジュール1
   X100    X1FF    入力モジュール2（必要な場合）
   X1000   X1035   実際の入力ポイントに合わせて調整
```

**GX Works3:**

```
1. [パラメータ] → [IO割付]
2. [インテリジェント機能モジュール] → [IO割付設定]
3. 入力モジュールの設定を行う
```

### 4.2 出力デバイス（Y）の設定

```
1. [Y]タブを選択
2. 以下の範囲を設定：

   開始    終了     コメント
   ─────────────────────────────────────
   Y000    Y0FF    出力モジュール1
   Y090    Y096    積層灯・ランプ
```

### 4.3 主要デバイスコメント例

| デバイス | コメント | 用途 |
|----------|----------|------|
| **入力（X）** |||
| X060 | 電源入力 | 電源監視 |
| X062 | 非常停止PB1 | 安全機器（二重化） |
| X063 | 非常停止PB2 | 安全機器（二重化） |
| X070 | 自動選択SW | モード選択 |
| X071 | 連動選択SW | モード選択 |
| X074 | 異常リセットPB | 操作ボタン |
| X076 | 起動PB | 操作ボタン |
| X077 | サイクル停止PB | 操作ボタン |
| X080 | B01非常停止1 | B01安全機器 |
| X088 | B02非常停止1 | B02安全機器 |
| **出力（Y）** |||
| Y090 | 積層灯R | 表示灯（赤） |
| Y091 | 積層灯Y | 表示灯（黄） |
| Y092 | 積層灯G | 表示灯（緑） |
| Y098 | 運転準備ランプ | 操作パネル |
| Y099 | 起動ランプ | 操作パネル |
| Y09A | サイクル停止ランプ | 操作パネル |

## 5. CC-Linkパラメータ設定

### 5.1 CC-Linkマスタ設定（GroundPanel PLC）

**GX Works2:**

```
1. [パラメータ] → [CC-Link]
2. [マスタ/ローカル] タブを選択
3. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   マスタ/ローカル          マスタ
   自動リフレッシュ         有効
   リンクリレー開始         B000
   リンクレジスタ開始       W000
   ステーション数           3（B01, B02, AGV）

4. [スレーブ] タブで各スレーブの設定：

   ステーション  デバイス範囲      用途
   ─────────────────────────────────────
   ステーション1  B000-B0FF      B01設備（Conveyor）
   ステーション2  B100-B1FF      B02設備（Conveyor）
   ステーション3  B200-B2FF      AGV設備
```

**重要:** リンクリレー（Bデバイス）の範囲は、ASCファイルで使用されている範囲をカバーする必要があります。

```
GroundPanelで使用されているBデバイス範囲：
- B00-B4F    : B01設備用
- B100-B11F  : B02設備用
- B1000-B1023: B01制御データ送信
- B1100-B1123: B02制御データ送信
```

### 5.2 CC-Linkスレーブ設定（Conveyor PLC）

```
1. [パラメータ] → [CC-Link]
2. [スレーブ] タブを選択
3. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   マスタ/ローカル          スレーブ
   自動リフレッシュ         有効
   リンクリレー開始         B000
   ステーション番号         1（B01）または 2（B02）
```

## 6. デバイスコメントのインポート

### 6.1 コメントファイルの作成（Excel）

Excelでデバイスコメントリストを作成します：

```excel
デバイス,コメント
M100,電源入
M101,非常停止正常
M102,非常停止異常
M103,DI_A01_非常停止PB正常1
M104,DI_A01_非常停止PB正常2
M105,スタッカーSC通信異常
D400,WMSから_タスクタイプ
D401,WMSから_タスクID
D402,WMSから_起点棚
D403,WMSから_起点列
D404,WMSから_起点層
...
```

### 6.2 コメントのインポート手順

**GX Works2:**

```
1. [ツール] → [デバイスコメント] → [インポート]
2. CSVファイルを選択
3. デバイス範囲を指定
4. [実行]をクリック
```

**GX Works3:**

```
1. [ツール] → [デバイスコメント] → [CSVファイルインポート]
2. CSVファイルを選択
3. インポート範囲を指定
4. [OK]をクリック
```

## 7. ASCファイルのインポート

### 7.1 インポート手順

**GX Works2:**

```
1. [ツール] → [ラダープログラムのインポート]
   または
   [プロジェクト] → [インポート] → [ラダープログラム]

2. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   インポートファイル         ASCファイルを選択
   プログラム名              MAIN（または適切な名前）
   プログラム種別            ラダー

3. [実行]をクリック
```

**GX Works3:**

```
1. [プロジェクト] → [インポート] → [ラダープログラム]
2. ASCファイルを選択
3. インポート先プログラムを指定
4. [OK]をクリック
```

### 7.2 インポート後の確認

```
1. プロジェクトツリーでラダープログラムを展開
2. ネットワークが正しく読み込まれているか確認
3. コメントが表示されているか確認
4. デバイス番号の色分け確認
   - 黒: 正常
   - 赤: 未定義デバイス（IOアサイン未設定）
```

## 8. コンパイルとエラーチェック

### 8.1 コンパイル手順

```
1. [ツール] → [コンパイル] または [F6]キー
2. コンパイル結果を確認：

   結果      対処
   ───────────────────────────────
   0件       正常
   エラーあり エラー内容を確認し修正
```

### 8.2 主なエラーと対処法

| エラー内容 | 原因 | 対処法 |
|-----------|------|--------|
| **デバイス未定義** | IOアサイン未設定 | パラメータ設定でデバイスを追加 |
| **デバイス重複** | 同じデバイスを2回使用 | ラダーロジックを確認 |
| **構文エラー** | ASCファイルの記述ミス | 元のASCファイルを確認 |
| **プログラム容量超過** | ステップ数がPLC容量を超過 | 上位モデルのPLCに変更 |

## 9. PLCへの書き込み

### 9.1 接続設定

```
1. [オンライン] → [接続先の設定]
2. 以下の設定を行う：

   項目                    設定値
   ──────────────────────────────────
   接続先I/F               USBまたはEthernet
   IPアドレス              192.168.X.X（実機のアドレス）
   ポート番号              5007（MCプロトコル）

3. [接続テスト]で通信確認
```

### 9.2 プログラム書き込み

```
1. [オンライン] → [PLCに書き込み]
2. 以下のオプションを確認：

   ☑ プログラム
   ☑ パラメータ
   ☑ デバイスコメント（必要な場合）
   ☑ IOアサイン

3. [実行]をクリック
4. 書き込み完了まで待機
```

## 10. 検証と動作確認

### 10.1 書き込み後の確認

```
1. [オンライン] → [モニタモード]
2. ラダープログラムの導通を確認
3. 入力デバイス（X）の状態を確認
4. 出力デバイス（Y）の強制ON/OFFテスト
```

### 10.2 CC-Link通信確認

```
1. CC-Link診断モードを起動
2. 以下の項目を確認：

   項目                    確認内容
   ──────────────────────────────────
   マスタステータス          正常通信中であること
   スレーブ接続状態          全スレーブが接続されていること
   リンクエラー             0であること
```

## 11. トラブルシューティング

### 11.1 よくある問題と解決策

| 問題 | 原因 | 解決策 |
|------|------|--------|
| **インポートできない** | ファイル形式が異なる | ASC形式であることを確認 |
| **デバイスが赤色表示** | IOアサイン未設定 | パラメータ設定でデバイス範囲を拡張 |
| **CC-Link通信しない** | ステーション番号不一致 | マスタ/スレーブの番号を確認 |
| **書き込みエラー** | PLCがRUNモード | PLCをSTOPモードに変更 |
| **通信エラー** | IPアドレス不一致 | 接続先設定を確認 |

### 11.2 エラーコード一覧

| エラーコード | 内容 | 対処 |
|-------------|------|------|
| E0101 | デバイス未定義 | IOアサインを追加 |
| E0203 | プログラム容量超過 | 上位モデルに変更 |
| E0305 | 構文エラー | ASCファイルの記述を確認 |
