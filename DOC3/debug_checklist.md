## 2. デバッグモードの選択確認

### 2.1 実機実装モード (Physical Mode) の場合
- [ ] 全てのPLCの `M8001` が **OFF** であることを確認する
- [ ] 非常停止SW (B01/B02のX62, X63) など物理入力が正しく反映されることを確認する
- [ ] CC-Linkケーブルが接続されていることを確認する

### 2.2 オフラインシミュレーションモード (Simulation Mode) の場合
- [ ] GX Worksのデバイスモニタ・テストにて、対象PLCの `M8001` を **ON (SET)** する
- [ ] 運転準備入・自動モードなど、物理I/Oに関わらず強制ONになることを確認する（M10 や CC-Link通信正常状態など）
- [ ] アラームデバイス `D456` に異常が残っている場合はリセット操作 (`X74`のON/OFF等) でクリアする

## 3. タスク制御ロジックの確認 (M8001=ON推奨)

### 3.1 B01 STロジック動作確認
- [ ] Lua (Modbus) から `D339` = 1001, `D340` = 0 を書き込み、タスク種別 `D330` = **100** になるか
- [ ] Lua (Modbus) から `D339` = 0, `D340` = 1002 を書き込み、タスク種別 `D330` = **200** になるか
- [ ] Lua (Modbus) から `D339` = 1001, `D340` = 1002 を書き込み、タスク種別 `D330` = **300** になるか

### 3.2 B02 STロジック動作確認
- [ ] Lua (Modbus) から `D339` = 1002, `D340` = 0 を書き込み、タスク種別 `D330` = **100** になるか
- [ ] Lua (Modbus) から `D339` = 0, `D340` = 1001 を書き込み、タスク種別 `D330` = **200** になるか
- [ ] Lua (Modbus) から `D339` = 1002, `D340` = 1001 を書き込み、タスク種別 `D330` = **300** になるか

### 3.3 コンベヤハンドシェイク確認 (REFACT3 新規実装部分)
- [ ] **B01 搬入:** `M1063` (CV1リフタ上限) と `M1057` (CV1在席) が共にONした時、`D212` が **1** (受取可) になるか
- [ ] **B01 搬出:** `M1079` (CV2リフタ上限) がON かつ `M1073` (CV2在席) がOFFした時、`D214` が **1** (受渡可) になるか
- [ ] **B02 搬入:** `M1248` (CV3受取可) がONした時、`D213` または対応デバイスが **1** になるか
- [ ] **B02 搬出:** 対応する出庫側在席がOFFの時、`D215` または対応デバイスが **1** になるか
