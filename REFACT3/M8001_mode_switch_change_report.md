# REFACT3 変更箇所調査レポート
## M8001 オフラインモード / 実装モード切り替え機能

**対象フォルダ:** REFACT2  
**目標:** 各GXWプログラムに `SM8001`（またはM8001）を用いたオフラインモード/実装モード切り替え機能を追加したREFACT3を作成する  
**作成日:** 2026-02-21

---

## 概要

### M8001 オフラインモードとは

M8001（SM8001相当のデバイス）をONにすることで、実機（実際の装置・センサー・通信）を使用しない**シミュレーション（オフライン）モード**に切り替える機能。  
実機が接続されていない状況でのデバッグ・テスト・開発を目的とする。

### 切り替えの基本ルール

| モード | M8001状態 | 動作 |
|--------|-----------|------|
| 実装モード（通常） | OFF | 実機の入力（X接点、CC-Link受信等）をそのまま使用 |
| オフラインモード | ON | 実機入力をバイパスし、全入力をON（またはソフト設定値）に固定 |

#### 【変更1】プログラム00: 入力処理 — 物理入力のバイパス

**対象行:** 3〜65行  
**変更理由:** 物理入力（X接点）を読んでいる全箇所で、オフラインモード時はX接点の代わりに固定値ONを出力する必要がある。

```diff
; 変更前（例: 電源入力）
  LD X60
  OUT M100    ;DI_電源入

; 変更後（M8001 ONでバイパス）
  LD M8001    ;オフラインモード
  OR X60
  OUT M100    ;DI_電源入
```

**対象となる全X接点読み取り箇所（行番号）:**

| 行番号 | 対象コード | コメント |
|--------|-----------|---------|
| 4 | `LD X60` → `OUT M100` | DI_電源入 |
| 10-12 | `LD X62 AND X63` → `OUT M40` | 非常停止PB正常（二重化） |
| 17 | `LDI X6C` → `OUT M112` | DI_盤クーラ異常 |
| 21 | `LDI X6D` → `OUT M113` | DI_Ethernet光伝送異常 |
| 27-30 | `LD X70/X71` → `OUT M116/M117` | 操作モード選択 |
| 33 | `LD X72` → `OUT M119` | DI_管理者モード入 |
| 37-44 | `LD X74/X76/X77/X78` → `OUT M120〜M124` | 操作ボタン各種 |
| 47-49 | `LD X7A AND X7B` → `OUT M10` | 運転準備入（二重化） |
| 52 | `LD X7E` → `OUT M130` | DI_STK電源MC_ON |
| 56-64 | `LD X80〜X85` | B01安全機器状態（二重化6点） |

**変更数:** 約15箇所（入力行単位）

#### 【変更2】プログラム01: CC-Link通信処理(受信) — B01設備状態受信のバイパス

**対象行:** 66〜173行  
**変更理由:** オフラインモード時は CC-Link実機が接続されていないため、B（ビットデバイス）からの受信を全てON（または適切な固定値）に置き換える。

```diff
; 変更前
  LD SM400    ;常時ON
  LD B00
  OUT M1000   ;CCLink_In_B01電源入

; 変更後
  LD SM400
  LD M8001    ;オフラインモードONならOFF→常時ONとして上書き
  OR B00
  OUT M1000   ;CCLink_In_B01電源入
```

ただし、**自動運転に必要なビット**（M1010:自動運転中、M1018:連動モード選択、M1048:STK受取可 等）については、オフラインモード時に強制ONすることで自動シーケンスが通るようにする。

**B接点の強制ON対象（主要なもの）:**

| 行番号 | 対象 | コメント |
|--------|------|---------|
| 68-83 | B00〜B07 → M1000〜M1007 | B01設備基本状態 |
| 84-97 | B0A〜B13 → M1010〜M1019 | B01運転モード・運転状態 |
| 118-173 | B30〜B4F → M1048〜M1079 | CV1/CV2 各種信号 |

**変更数:** 約40箇所（LDビット毎）、グループ化して8〜10のブロック

### 実装上の注意点

1. **M8001 の定義について**  
   三菱電機 Q/iQシリーズでは `SM8001` はシステムメモリのため、ユーザー領域の内部リレー（例: `M8001`）として定義する場合は以下のいずれかで制御する：
   - HMIタッチパネルから書き込み（推奨）
   - GX Works3 ソフトデバイスで手動セット
   - 専用スイッチからの物理入力でON/OFF

2. **オフライン→実装モード復帰時の初期化**  
   M8001 OFFの立ち下がりパルス（`LDF M8001`）で、バイパス中に発生したアラームリセット・データクリアを再実行する処理も必要。

3. **CC-Link通信エラー対策**  
   オフラインモード中は SB49（CC-Link通信エラービット）が立つ可能性があるため、SB49が OFFになるまで通信異常フラグを M8001で抑制する処理が必要。

4. **StackerCrane の U0/U2通信ブロック（BLOCK_09）**  
   ファイル量が多く、今回の調査では800行〜1600行付近（BLOCK_07途中）まで読み込んだ。  
   **BLOCK_09（通信処理）の詳細な変更箇所は追加調査が推奨される。**
